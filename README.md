
# Fenvora Infotech – Internship Portal

**Technology That Moves Business Forward.**

A modern, responsive internship portal website for **Fenvora Infotech Pvt. Ltd.** that helps students explore internship opportunities and apply through an online application form.

## 🚀 Features

- Professional and responsive website design
- Company branding and logo integration
- Internship opportunities with role descriptions
- Dedicated sections for Home, Internships, and About Us
- Online application through Google Forms
- Responsive navigation and mobile-friendly layout
- Internship categories covering development, AI, and cloud technologies
- Reusable React components
- Modern user interface with CSS styling

## 💼 Internship Opportunities

## ⚙️ Installation and Setup

### Prerequisites

- Node.js
- npm
- Visual Studio Code

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd YOUR_PROJECT_FOLDER/client
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the website

Visit:

```text
http://localhost:5173/
```

## 🖼️ Logo Setup

Place the company logo inside the `public` directory:

```text
client/public/fenvora-logo.png
```

Use the following path in React:

```tsx
<img
  src="/fenvora-logo.png"
  alt="Fenvora Infotech logo"
  className="company-logo"
/>
```

## 📝 Application Process

1. Explore the available internship opportunities.
2. Select the internship role you are interested in.
3. Click the Apply button.
4. Complete the online application form.
5. Submit your application for consideration.
